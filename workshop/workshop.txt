description=KnoxMap turns any real place into a playable Project Zomboid Build 42 map: real streets, real buildings, furnished inside, with loot, zombies and cars where they belong.
description=
description=KnoxMap is a free program you run on your own PC, not a subscription. Get it from GitHub:
description=https://github.com/spytheeuclidean-a11y/knoxmap/releases/latest
description=
description=WHAT THIS ITEM IS
description=A small tool that comes with KnoxMap, put here on its own because it is useful in any map, the ones that ship with the game included.
description=
description=Reset loot - right-click the ground and pick "Reset loot": every container in that building, or everything within 30 tiles, is filled again from the game's own loot tables. No new save needed. Useful when you have picked a town clean, when you install a map again, or when a map you are building changes under you. It asks first, and it never touches a vehicle, a corpse or anyone's inventory.
description=
description=It does not generate maps. That is KnoxMap itself, from the link above.
description=
description=WHAT KNOXMAP MAKES
description=Streets, pavements, kerbs, road markings, rivers, coastline, woods, railways, bridges and overpasses, from OpenStreetMap. Every building on its real outline and furnished inside: houses, flats, shops with their stockrooms, schools, churches, works, police stations, libraries, fire stations. Rooms named the way the game names them, so the loot in a pharmacy is a pharmacy's. Zombies from an estimate of who lived and worked in each block. Cars, petrol pumps, graveyards, army bases, and the paper map you open with M.
description=
description=WHAT YOU NEED
description=Project Zomboid Build 42 - Build 41 cannot load these maps. KnoxMap reads the place from a Geofabrik extract on your PC. Its own setup fetches the map tools and extracts the tile artwork from your copy of the game; nothing comes from anyone else's.
description=
description=Windows, Linux or macOS. On Linux the map compiler comes built for Linux, so there is no Wine and nothing to install; on macOS the map tools run through Wine.
